This repo is made for sharing code about geospatial treatments and other things related to GIS.
Feel free to copy and take the code out of this repo and reuse it as you want!

- The folder data contains all the code files about automated fetching for datasets in the "téléchargement" and "diffusion" API of the Géoplateforme by IGN (France)
- The folder qgis contains the file to initiate the QGIS environment out of the QGIS UI.
With the files in this folder, you can set up your own QGIS environment in VSCode (for instance) or other code editor.

The development files here are mainly in Python, but in the future I may release new files in different languages.
